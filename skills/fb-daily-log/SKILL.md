---
name: fb-daily-log
description: Append a concise record of fundraising wiki changes or a saved analysis to the private daily log.
---

Read `AGENTS.md`. Use `workspace/wiki/logs/YYYY-MM-DD.md` with a date heading. Read the existing file first, then append a time, action, outcome, and wiki links to changed pages. Preserve previous entries and completion markers.

Log substantive interaction updates, research, applied review decisions, and saved analyses. A question that produced no saved result needs no log entry. Log failures as partial work without claiming success.

Do not write a `daily-check-completed` marker manually. Only the daily-check workflow and checkpoint command may mark a reviewed email window complete. Logs are private; never move them to the public dataset or release documentation.
